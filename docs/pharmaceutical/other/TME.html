Tumor Microenvironment, TME（肿瘤微环境）

Oncology
Disease Overview
Clinical Trials
系统介绍肿瘤微环境的组成、免疫调控机制、临床意义及其在肿瘤药物研发中的应用。
Author

Hao Sun

Published

July 2, 2026

1 概述

Tumor microenvironment, TME（肿瘤微环境）是指肿瘤细胞周围所有非肿瘤成分所组成的复杂生态系统，包括免疫细胞、基质细胞、血管、淋巴管、细胞外基质（Extracellular Matrix, ECM）以及各种细胞因子和生长因子。

现代肿瘤学认为，癌症并不仅仅是肿瘤细胞本身的疾病，而是肿瘤细胞与其微环境共同演化（co-evolution）的结果。TME不仅影响肿瘤发生、侵袭和转移，也决定了患者对化疗、靶向治疗及免疫治疗的反应，因此已成为当前抗肿瘤药物研发的重要靶点。

4 TME的主要生物学功能

4.1 促进肿瘤生长

肿瘤细胞通过释放多种生长因子，刺激周围基质细胞和免疫细胞，共同形成有利于肿瘤生长的环境。

例如：

  • VEGF促进血管生成；
  • TGF-beta促进纤维化；
  • IL-6促进炎症反应；
  • PDGF促进CAF活化。

4.2 血管生成（Angiogenesis）

随着肿瘤体积增大，原有血管无法满足营养需求。

肿瘤会分泌：

  • VEGF；
  • FGF；
  • PDGF；

刺激新生血管形成。

但这些血管通常：

  • 结构异常；
  • 渗漏严重；
  • 血流紊乱；
  • 导致低氧（Hypoxia）。

低氧又进一步刺激VEGF形成正反馈。

4.3 免疫逃逸（Immune Evasion）

这是目前免疫治疗最重要的理论基础。

正常情况下：

Cancer cell
      ↓
Antigen presentation
      ↓
CD8 T cell activation
      ↓
Tumor killing

但是肿瘤会建立免疫抑制环境：

  • PD-L1高表达；
  • Treg增加；
  • MDSC聚集；
  • TAM向M2型极化；
  • 抑制DC成熟；
  • 分泌IL-10、TGF-beta。

最终导致：

T细胞进入肿瘤后逐渐失去杀伤能力（T cell exhaustion）。

4.4 肿瘤转移

TME可促进：

  • 上皮-间质转化（Epithelial-mesenchymal transition, EMT）；
  • 基底膜降解；
  • 新生血管形成；
  • 淋巴转移；
  • 肿瘤细胞进入循环。

因此，TME也是肿瘤转移的重要驱动力。

5 TME中的免疫细胞

细胞 抗肿瘤作用 促肿瘤作用
CD8 T cells 强 无
NK cells 强 无
DCs 强 少
B cells 中等 部分情况下促进
Treg 无 强
MDSCs 无 强
TAM M1 强 无
TAM M2 无 强
CAFs 很弱 很强

通常认为：

CD8越多越好。

Treg、MDSC、M2 TAM越少越好。

6 TME的免疫表型（Immune Phenotypes）

目前通常将TME分为三类。

类型 特点 对免疫治疗反应
Immune-inflamed (“Hot tumor”) 大量T细胞浸润 最好
Immune-excluded T细胞停留于肿瘤边缘 中等
Immune-desert (“Cold tumor”) 几乎没有免疫细胞 最差

这是解释为什么相同PD-L1表达患者疗效不同的重要原因之一。

8 TME与抗肿瘤治疗

8.1 Immune Checkpoint Inhibitors

代表药物：

  • Pembrolizumab；
  • Nivolumab；
  • Atezolizumab；
  • Durvalumab。

作用：

解除T细胞抑制。

8.2 Anti-VEGF Therapy

代表药物：

  • Bevacizumab；
  • Ivonescimab。

抗VEGF治疗不仅减少血管生成，同时可以：

  • 改善T细胞进入；
  • 降低免疫抑制；
  • 增强PD-1疗效。

因此目前大量研究采用：

Anti-PD-1 + Anti-VEGF

联合治疗。

8.3 CAR-T

CAR-T不仅需要识别肿瘤，还必须克服：

  • CAF屏障；
  • ECM阻碍；
  • TGF-beta；
  • MDSC。

因此实体瘤CAR-T最大的困难实际上来自TME。

8.4 ADC

ADC释放毒素后：

  • 可直接杀伤肿瘤；
  • 可诱导免疫原性细胞死亡（Immunogenic Cell Death, ICD）；
  • 增加抗原释放；
  • 激活TME。

因此ADC与IO联合也是当前热点方向。

9 TME在临床试验中的意义

近年来，越来越多临床试验将TME相关指标作为探索性终点（Exploratory Endpoints）或生物标志物。

常见评估指标包括：

指标 临床意义
PD-L1表达 预测免疫治疗获益
CD8浸润 判断Hot tumor
TMB 预测新抗原数量
IFN-gamma signature 反映免疫激活程度
Gene Expression Profile (GEP) 综合评估免疫微环境
Treg比例 反映免疫抑制程度
MDSC水平 反映免疫抑制程度
TAM极化状态 判断促肿瘤环境
VEGF表达 判断血管生成活跃程度

这些指标通常用于：

  • 患者分层（Patient Stratification）；
  • Biomarker分析；
  • 亚组分析（Subgroup Analysis）；
  • 机制研究（Mechanistic Study）。

10 生物统计学考虑

TME相关研究具有较强的生物学异质性，在临床试验设计与分析中需要充分考虑统计问题：

  • Biomarker-driven trial（生物标志物驱动试验）需要预先定义阳性阈值和检测方法，避免数据驱动的cutoff选择。
  • TME指标通常连续分布，既可按连续变量建模，也可按预设阈值分类，但后者可能损失信息。
  • 多个TME生物标志物联合分析时，应控制family-wise type I error rate（FWER）或false discovery rate（FDR），避免多重比较带来的假阳性。
  • 肿瘤内及肿瘤间异质性可能导致取样偏倚，应尽可能标准化组织采集时间、部位和检测平台。
  • TME生物标志物既可作为预测性生物标志物（Predictive Biomarker），也可作为预后性生物标志物（Prognostic Biomarker），分析时需明确研究目的。

11 常见误区

  1. TME不等于免疫细胞。
    它还包括血管、基质细胞、ECM及多种可溶性因子。

  2. PD-L1高表达并不一定意味着免疫治疗有效。
    TME整体状态、CD8+ T细胞浸润及其他免疫抑制机制同样重要。

  3. Hot tumor并非永久状态。
    TME具有动态变化特征，可随治疗、疾病进展及耐药而改变。

  4. 血管生成不仅影响供血。
    VEGF还能通过多种机制抑制免疫细胞功能，因此抗VEGF治疗具有免疫调节作用。

12 Key Takeaways

  1. TME是由肿瘤细胞、免疫细胞、基质细胞、血管及ECM共同组成的复杂生态系统。
  2. TME在肿瘤发生、进展、转移及耐药过程中发挥核心作用。
  3. 免疫逃逸是TME最重要的功能之一，也是免疫检查点抑制剂发挥作用的理论基础。
  4. TME可分为Hot、Immune-excluded和Cold三种免疫表型，不同表型对免疫治疗反应显著不同。
  5. PD-1/PD-L1、VEGF、TGF-beta、CTLA-4、LAG-3和TIGIT等均是TME的重要治疗靶点。
  6. TME相关生物标志物已广泛应用于患者分层、疗效预测及新药研发，并对临床试验设计和生物统计分析提出了新的挑战。

- 淋巴转移；
- 肿瘤细胞进入循环。

因此，TME也是肿瘤转移的重要驱动力。

# TME中的免疫细胞

| 细胞 | 抗肿瘤作用 | 促肿瘤作用 |
|---|---|---|
| CD8 T cells | 强 | 无 |
| NK cells | 强 | 无 |
| DCs | 强 | 少 |
| B cells | 中等 | 部分情况下促进 |
| Treg | 无 | 强 |
| MDSCs | 无 | 强 |
| TAM M1 | 强 | 无 |
| TAM M2 | 无 | 强 |
| CAFs | 很弱 | 很强 |

通常认为：

**CD8越多越好。**

**Treg、MDSC、M2 TAM越少越好。**

# TME的免疫表型（Immune Phenotypes）

目前通常将TME分为三类。

| 类型 | 特点 | 对免疫治疗反应 |
|---|---|---|
| Immune-inflamed ("Hot tumor") | 大量T细胞浸润 | 最好 |
| Immune-excluded | T细胞停留于肿瘤边缘 | 中等 |
| Immune-desert ("Cold tumor") | 几乎没有免疫细胞 | 最差 |

这是解释为什么相同[PD-L1表达](Biomarker_Expression.qmd)患者疗效不同的重要原因之一。

# TME相关的重要信号通路

| 通路 | 作用 |
|---|---|
| [PD-1/PD-L1](Immune_Checkpoint.qmd) | T细胞抑制 |
| CTLA-4 | T细胞激活抑制 |
| [VEGF](../target/VEGF.qmd) | 血管生成、免疫抑制 |
| TGF-beta | 纤维化、免疫抑制 |
| CSF-1/CSF1R | TAM募集 |
| CXCL12/CXCR4 | T细胞排斥 |
| IDO | 色氨酸代谢，抑制T细胞 |
| Adenosine (CD39/CD73) | 抑制免疫细胞 |
| TIGIT | 新型免疫检查点 |
| LAG-3 | 新型免疫检查点 |
| TIM-3 | 新型免疫检查点 |

# TME与抗肿瘤治疗

## Immune Checkpoint Inhibitors

代表药物：

- [Pembrolizumab](../compound/Keytruda.qmd)；
- [Nivolumab](../compound/Opdivo.qmd)；
- [Atezolizumab](../compound/Tecentriq.qmd)；
- [Durvalumab](../compound/Imfinzi.qmd)。

作用：

解除T细胞抑制。

## Anti-VEGF Therapy

代表药物：

- [Bevacizumab](../compound/Avastin.qmd)；
- [Ivonescimab](../compound/Ivonescimab.qmd)。

抗VEGF治疗不仅减少血管生成，同时可以：

- 改善T细胞进入；
- 降低免疫抑制；
- 增强PD-1疗效。

因此目前大量研究采用：

> Anti-PD-1 + Anti-VEGF

联合治疗。

## CAR-T

[CAR-T](CAR-T.qmd)不仅需要识别肿瘤，还必须克服：

- CAF屏障；
- ECM阻碍；
- TGF-beta；
- MDSC。

因此实体瘤CAR-T最大的困难实际上来自TME。

## ADC

[ADC](ADC.qmd)释放毒素后：

- 可直接杀伤肿瘤；
- 可诱导免疫原性细胞死亡（Immunogenic Cell Death, ICD）；
- 增加抗原释放；
- 激活TME。

因此ADC与IO联合也是当前热点方向。

# TME在临床试验中的意义

近年来，越来越多临床试验将TME相关指标作为探索性终点（Exploratory Endpoints）或[生物标志物](Biomarker.qmd)。

常见评估指标包括：

| 指标 | 临床意义 |
|---|---|
| PD-L1表达 | 预测免疫治疗获益 |
| CD8浸润 | 判断Hot tumor |
| TMB | 预测新抗原数量 |
| IFN-gamma signature | 反映免疫激活程度 |
| Gene Expression Profile (GEP) | 综合评估免疫微环境 |
| Treg比例 | 反映免疫抑制程度 |
| MDSC水平 | 反映免疫抑制程度 |
| TAM极化状态 | 判断促肿瘤环境 |
| VEGF表达 | 判断血管生成活跃程度 |

这些指标通常用于：

- 患者分层（Patient Stratification）；
- Biomarker分析；
- 亚组分析（Subgroup Analysis）；
- 机制研究（Mechanistic Study）。

# 生物统计学考虑

TME相关研究具有较强的生物学异质性，在临床试验设计与分析中需要充分考虑统计问题：

- **Biomarker-driven trial（生物标志物驱动试验）**需要预先定义阳性阈值和检测方法，避免数据驱动的cutoff选择。
- TME指标通常连续分布，既可按连续变量建模，也可按预设阈值分类，但后者可能损失信息。
- 多个TME生物标志物联合分析时，应控制**family-wise type I error rate（FWER）**或**false discovery rate（FDR）**，避免多重比较带来的假阳性。
- 肿瘤内及肿瘤间异质性可能导致取样偏倚，应尽可能标准化组织采集时间、部位和检测平台。
- TME生物标志物既可作为预测性生物标志物（Predictive Biomarker），也可作为预后性生物标志物（Prognostic Biomarker），分析时需明确研究目的。

# 常见误区

1. **TME不等于免疫细胞。**  
   它还包括血管、基质细胞、ECM及多种可溶性因子。

2. **PD-L1高表达并不一定意味着免疫治疗有效。**  
   TME整体状态、CD8+ T细胞浸润及其他免疫抑制机制同样重要。

3. **Hot tumor并非永久状态。**  
   TME具有动态变化特征，可随治疗、疾病进展及耐药而改变。

4. **血管生成不仅影响供血。**  
   VEGF还能通过多种机制抑制免疫细胞功能，因此抗VEGF治疗具有免疫调节作用。

# Key Takeaways

1. TME是由肿瘤细胞、免疫细胞、基质细胞、血管及ECM共同组成的复杂生态系统。
2. TME在肿瘤发生、进展、转移及耐药过程中发挥核心作用。
3. 免疫逃逸是TME最重要的功能之一，也是免疫检查点抑制剂发挥作用的理论基础。
4. TME可分为Hot、Immune-excluded和Cold三种免疫表型，不同表型对免疫治疗反应显著不同。
5. PD-1/PD-L1、VEGF、TGF-beta、CTLA-4、LAG-3和TIGIT等均是TME的重要治疗靶点。
6. TME相关生物标志物已广泛应用于患者分层、疗效预测及新药研发，并对临床试验设计和生物统计分析提出了新的挑战。
