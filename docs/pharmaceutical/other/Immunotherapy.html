Immunotherapy（肿瘤免疫治疗）

Oncology
Drug Development
Clinical Trials
系统介绍肿瘤免疫治疗的基本原理、主要治疗策略、临床应用及其在肿瘤药物研发中的重要地位。
Author

Hao Sun

Published

September 11, 2026

1 概述

Immunotherapy（肿瘤免疫治疗）是利用或增强人体免疫系统识别并清除肿瘤细胞的一类治疗方法。与化疗（chemotherapy）或靶向治疗（targeted therapy）直接作用于肿瘤细胞不同，免疫治疗主要通过调节宿主免疫系统，使其恢复或增强抗肿瘤能力。

过去十余年，免疫治疗已成为继手术、放疗、化疗和靶向治疗之后的重要肿瘤治疗支柱。尤其是immune checkpoint inhibitors（免疫检查点抑制剂）的出现，彻底改变了包括Non-small cell lung cancer, NSCLC（非小细胞肺癌）、Melanoma（黑色素瘤）、renal cell carcinoma, RCC（肾细胞癌）等多种恶性肿瘤的治疗格局。

2 为什么免疫治疗能够发挥作用？

正常情况下，人体免疫系统能够识别并清除异常细胞，这一过程称为immune surveillance（免疫监视）。

肿瘤细胞在长期进化过程中形成了多种immune evasion（免疫逃逸）机制，例如：

  • 表达PD-L1抑制T细胞活化；
  • 招募regulatory T cells（Treg）；
  • 招募myeloid-derived suppressor cells（MDSCs）；
  • 建立免疫抑制性的tumor microenvironment, TME（肿瘤微环境）；
  • 降低抗原表达；
  • 下调MHC分子。

免疫治疗的核心目标就是解除这些免疫抑制，使免疫系统重新识别并攻击肿瘤。

3 肿瘤免疫循环（Cancer-Immunity Cycle）

目前最经典的理论模型为Cancer-Immunity Cycle。

Tumor cell death
        ↓
Tumor antigen release
        ↓
Antigen presentation
        ↓
T-cell activation
        ↓
T-cell trafficking
        ↓
Tumor infiltration
        ↓
Tumor recognition
        ↓
Tumor killing
        ↓
（循环再次开始）

免疫治疗可以作用于循环中的不同环节，因此不同类型的免疫治疗具有不同机制。

5 Immune Checkpoint Inhibitors（免疫检查点抑制剂）

这是目前应用最广泛的免疫治疗策略。

     │
   PD-L1
     │
     ▼

     │
T-cell inhibition

PD-1或PD-L1抗体可阻断这一抑制信号，使T细胞重新恢复杀伤功能。

7 CAR-T Cell Therapy（CAR-T细胞治疗）

CAR-T治疗流程包括：

  1. 采集患者T细胞；
  2. 基因工程改造表达CAR；
  3. 体外扩增；
  4. 回输患者体内；
  5. CAR-T识别并杀伤肿瘤。

目前CAR-T主要用于：

  • B细胞急性淋巴细胞白血病（B-ALL）；
  • 大B细胞淋巴瘤（DLBCL）；
  • 多发性骨髓瘤（MM）。

实体瘤CAR-T仍面临TME、抗原异质性及细胞浸润不足等挑战。

8 双特异性抗体（Bispecific Antibodies）

双抗可同时结合：

  • CD3（T细胞）；
  • 肿瘤抗原。

从而直接将T细胞募集到肿瘤附近并诱导细胞毒作用。

典型代表包括：

药物 靶点
Blinatumomab CD19 × CD3
Tarlatamab DLL3 × CD3
Cadonilimab PD-1 × CTLA-4
Ivonescimab PD-1 × VEGF
Pumitamig PD-L1 × VEGF-A

9 Immunotherapy联合治疗

目前越来越多研究采用联合治疗策略。

联合方案 理论基础
PD-1 + Chemotherapy 增加抗原释放
PD-1 + VEGF 改善TME，提高T细胞浸润
PD-1 + CTLA-4 增强不同阶段T细胞活化
PD-1 + ADC 诱导免疫原性细胞死亡
PD-1 + Radiotherapy 放疗促进抗原释放
PD-1 + Targeted Therapy 提高免疫敏感性（部分癌种）

近年来，PD-1 + VEGF及PD-1 + ADC成为实体瘤的重要研发方向。

10 Biomarkers（生物标志物）

并非所有患者都能从免疫治疗中获益，因此需要生物标志物帮助筛选患者。

Biomarker 临床意义
PD-L1表达 最常用预测指标
Tumor mutational burden, TMB（肿瘤突变负荷） 新抗原水平
Microsatellite instability-high, MSI-H（微卫星高度不稳定） 高度预测获益
Mismatch repair deficiency, dMMR（错配修复缺陷） FDA组织无关适应证
CD8浸润 反映Hot tumor
IFN-gamma signature 反映免疫激活状态
Gene expression profile, GEP 综合免疫评分

需要注意，单一生物标志物预测能力有限，多标志物联合评估逐渐成为趋势。

11 常见不良反应

免疫治疗最具特点的是immune-related adverse events, irAEs（免疫相关不良事件），主要由免疫系统过度激活所致。

系统 常见irAE
皮肤 皮疹、瘙痒、白癜风
消化道 免疫性结肠炎
肺 免疫性肺炎
肝 肝炎
内分泌 甲状腺炎、垂体炎、肾上腺功能不全
肾 肾炎
心脏 心肌炎（少见但严重）

多数轻中度irAE可通过暂停治疗及糖皮质激素控制。

12 Immunotherapy在临床试验中的特点

免疫治疗具有与传统抗肿瘤药物不同的疗效特征，因此试验设计需特别考虑：

  • 部分患者可出现delayed response（延迟应答）。
  • 少数患者可能发生pseudoprogression（假性进展），即影像学短暂增大后出现肿瘤缩小。
  • 生存曲线常表现为delayed separation（延迟分离），违反比例风险假设。
  • 部分患者获得长期缓解，形成long-tail effect（长尾效应）。

因此，传统RECIST 1.1评价标准有时需结合iRECIST（免疫RECIST）进行疗效评估。

13 生物统计学考虑

免疫治疗临床试验具有一些特殊统计学挑战：

  • Overall survival, OS（总生存期）通常仍是最重要终点，但progression-free survival, PFS（无进展生存期）可能低估长期获益。
  • 由于存在延迟治疗效应，Cox比例风险模型的proportional hazards assumption（比例风险假设）可能不成立，可考虑使用restricted mean survival time, RMST（限制性平均生存时间）、加权log-rank检验或其他非比例风险分析方法。
  • 假性进展可能影响PFS事件判定，因此需明确RECIST或iRECIST的应用原则。
  • Biomarker阳性亚组分析应预先定义，并控制多重比较导致的第一类错误。
  • 长期生存平台效应使长期随访及成熟OS分析尤为重要。

14 常见误区

  1. 免疫治疗并非所有患者都有效。
    不同肿瘤类型及不同患者之间疗效差异显著。

  2. PD-L1阴性并不意味着一定无效。
    PD-L1只是预测指标之一，并非绝对标准。

  3. 免疫治疗起效通常较慢。
    部分患者在早期影像学评估时可能未表现出明显缩瘤。

  4. 免疫治疗副作用通常不是传统化疗毒性。
    其核心特点是免疫相关炎症反应，而非骨髓抑制或脱发。

  5. 免疫治疗并不局限于PD-1/PD-L1。
    CAR-T、双抗、肿瘤疫苗、溶瘤病毒及新型免疫检查点均属于广义免疫治疗。

15 Key Takeaways

  1. Immunotherapy通过激活或恢复人体免疫系统发挥抗肿瘤作用，是现代肿瘤治疗的重要支柱。
  2. Immune checkpoint inhibitors是目前应用最广泛的免疫治疗，包括PD-1、PD-L1和CTLA-4抑制剂。
  3. CAR-T、双特异性抗体、肿瘤疫苗及溶瘤病毒等代表了免疫治疗的重要发展方向。
  4. TME和免疫逃逸机制是免疫治疗研发的重要理论基础。
  5. PD-L1、MSI-H/dMMR、TMB及CD8浸润等生物标志物有助于预测治疗获益，但目前尚无完美预测指标。
  6. 免疫治疗具有延迟应答、假性进展及长尾生存等特点，对临床试验设计和统计分析提出了新的要求。

## CTLA-4抑制剂

CTLA-4主要作用于T细胞初始激活阶段。

| 通用名 | 公司 | 商品名 |
|---|---|---|

# CAR-T Cell Therapy（CAR-T细胞治疗）

[CAR-T](CAR-T.qmd)治疗流程包括：

1. 采集患者T细胞；
2. 基因工程改造表达CAR；
3. 体外扩增；
4. 回输患者体内；
5. CAR-T识别并杀伤肿瘤。

目前CAR-T主要用于：

- B细胞急性淋巴细胞白血病（B-ALL）；
- 大B细胞淋巴瘤（DLBCL）；
- [多发性骨髓瘤](../disease/multiple_myeloma.qmd)（MM）。

实体瘤CAR-T仍面临TME、抗原异质性及细胞浸润不足等挑战。

# 双特异性抗体（Bispecific Antibodies）

双抗可同时结合：

- CD3（T细胞）；
- 肿瘤抗原。

从而直接将T细胞募集到肿瘤附近并诱导细胞毒作用。

典型代表包括：

| 药物 | 靶点 |
|---|---|
| Blinatumomab | CD19 × CD3 |
| Tarlatamab | DLL3 × CD3 |
| [Cadonilimab](../compound/Cadonilimab.qmd) | PD-1 × CTLA-4 |
| [Ivonescimab](../compound/Ivonescimab.qmd) | PD-1 × [VEGF](../target/VEGF.qmd) |
| [Pumitamig](../compound/Pumitamig.qmd) | PD-L1 × VEGF-A |

# Immunotherapy联合治疗

目前越来越多研究采用联合治疗策略。

| 联合方案 | 理论基础 |
|---|---|
| PD-1 + Chemotherapy | 增加抗原释放 |
| PD-1 + VEGF | 改善TME，提高T细胞浸润 |
| PD-1 + CTLA-4 | 增强不同阶段T细胞活化 |
| PD-1 + [ADC](ADC.qmd) | 诱导免疫原性细胞死亡 |
| PD-1 + Radiotherapy | 放疗促进抗原释放 |
| PD-1 + Targeted Therapy | 提高免疫敏感性（部分癌种） |

近年来，**PD-1 + VEGF**及**PD-1 + ADC**成为实体瘤的重要研发方向。

# Biomarkers（生物标志物）

并非所有患者都能从免疫治疗中获益，因此需要[生物标志物](Biomarker.qmd)帮助筛选患者。

| Biomarker | 临床意义 |
|---|---|
| [PD-L1表达](Biomarker_Expression.qmd) | 最常用预测指标 |
| Tumor mutational burden, TMB（肿瘤突变负荷） | 新抗原水平 |
| Microsatellite instability-high, MSI-H（微卫星高度不稳定） | 高度预测获益 |
| Mismatch repair deficiency, dMMR（错配修复缺陷） | FDA组织无关适应证 |
| CD8浸润 | 反映Hot tumor |
| IFN-gamma signature | 反映免疫激活状态 |
| Gene expression profile, GEP | 综合免疫评分 |

需要注意，单一生物标志物预测能力有限，多标志物联合评估逐渐成为趋势。

# 常见不良反应

免疫治疗最具特点的是**immune-related adverse events, irAEs（免疫相关不良事件）**，主要由免疫系统过度激活所致。

| 系统 | 常见irAE |
|---|---|
| 皮肤 | 皮疹、瘙痒、白癜风 |
| 消化道 | 免疫性结肠炎 |
| 肺 | 免疫性肺炎 |
| 肝 | 肝炎 |
| 内分泌 | 甲状腺炎、垂体炎、肾上腺功能不全 |
| 肾 | 肾炎 |
| 心脏 | 心肌炎（少见但严重） |

多数轻中度irAE可通过暂停治疗及糖皮质激素控制。

# Immunotherapy在临床试验中的特点

免疫治疗具有与传统抗肿瘤药物不同的疗效特征，因此试验设计需特别考虑：

- 部分患者可出现**delayed response（延迟应答）**。
- 少数患者可能发生**pseudoprogression（假性进展）**，即影像学短暂增大后出现肿瘤缩小。
- 生存曲线常表现为**delayed separation（延迟分离）**，违反比例风险假设。
- 部分患者获得长期缓解，形成**long-tail effect（长尾效应）**。

因此，传统[RECIST 1.1](RECIST_1_1.qmd)评价标准有时需结合**iRECIST（免疫RECIST）**进行疗效评估。

# 生物统计学考虑

免疫治疗临床试验具有一些特殊统计学挑战：

- **Overall survival, OS（总生存期）**通常仍是最重要终点，但**[progression-free survival, PFS（无进展生存期）](PFS.qmd)**可能低估长期获益。
- 由于存在延迟治疗效应，Cox比例风险模型的**proportional hazards assumption（比例风险假设）**可能不成立，可考虑使用**restricted mean survival time, RMST（限制性平均生存时间）**、加权log-rank检验或其他非比例风险分析方法。
- 假性进展可能影响PFS事件判定，因此需明确RECIST或iRECIST的应用原则。
- Biomarker阳性亚组分析应预先定义，并控制多重比较导致的第一类错误。
- 长期生存平台效应使长期随访及成熟OS分析尤为重要。

# 常见误区

1. **免疫治疗并非所有患者都有效。**  
   不同肿瘤类型及不同患者之间疗效差异显著。

2. **PD-L1阴性并不意味着一定无效。**  
   PD-L1只是预测指标之一，并非绝对标准。

3. **免疫治疗起效通常较慢。**  
   部分患者在早期影像学评估时可能未表现出明显缩瘤。

4. **免疫治疗副作用通常不是传统化疗毒性。**  
   其核心特点是免疫相关炎症反应，而非骨髓抑制或脱发。

5. **免疫治疗并不局限于PD-1/PD-L1。**  
   CAR-T、双抗、肿瘤疫苗、溶瘤病毒及新型免疫检查点均属于广义免疫治疗。

# Key Takeaways

1. Immunotherapy通过激活或恢复人体免疫系统发挥抗肿瘤作用，是现代肿瘤治疗的重要支柱。
2. Immune checkpoint inhibitors是目前应用最广泛的免疫治疗，包括PD-1、PD-L1和CTLA-4抑制剂。
3. CAR-T、双特异性抗体、肿瘤疫苗及溶瘤病毒等代表了免疫治疗的重要发展方向。
4. TME和免疫逃逸机制是免疫治疗研发的重要理论基础。
5. PD-L1、MSI-H/dMMR、TMB及CD8浸润等生物标志物有助于预测治疗获益，但目前尚无完美预测指标。
6. 免疫治疗具有延迟应答、假性进展及长尾生存等特点，对临床试验设计和统计分析提出了新的要求。
